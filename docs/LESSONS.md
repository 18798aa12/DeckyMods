# 已发生问题与防回归要求

## 发布与运行环境

| 曾发生的问题 | 原因 | 后续必须检查 |
| --- | --- | --- |
| 安装窗口停在最后，新版无法启动 | 系统 Python 有的 html.parser 在 Decky 冻结 Python 中不存在 | 保留独立进程缺失模块导入回归；新增依赖检查打包后导入；不能仅凭复制 ZIP 判断安装成功 |
| 后端安装完成，安装窗口仍残留 | 程序直接确认原生安装请求，没有结束对应窗口 | 原生确认和 UI 完成状态分开核验；不重启整个 Decky 或影响其他插件 |
| 系统 Python 能联网，Decky 更新失败 | 冻结运行时默认证书库为空 | 保留真实空证书库回归及系统 CA 回退，证书与主机名校验始终开启 |
| HTTP keepalive 读取失败 | 响应体读取前关闭了连接 | 响应拥有连接生命周期；覆盖 JSON、文件、跳转、取消及错误响应的真实 HTTP/1.1 测试 |
| TUN 下域名变成虚拟 IP 后被拒绝 | 安全公网检查与 fake-IP DNS 的差异 | 仅在允许域名且所有答案均为虚拟地址时安全解析真实地址；保留私网、混合答案和 TLS 拒绝测试 |
| 发布源码可能带出私人环境或历史 | 原始仓库历史、私有缓存和发行包没有相同隐私边界 | 独立脱敏发布仓库，源码与 ZIP 都检查；仅打包明确允许的文件 |

## 游戏与 MOD 数据

| 曾发生的问题 | 原因 | 后续必须检查 |
| --- | --- | --- |
| 只显示生化危机，看不到其他已安装游戏 | 默认系列筛选加上固定目录表 | 默认显示所有已安装游戏；从受校验的 Steam 清单发现其他游戏；排除运行工具 |
| 新增适配可能让旧 MOD 从列表消失 | steam-APPID 被新目录 ID 替代 | 保留持久身份、旧安装模式和任务；断盘保留记录，重连重新验证，不借用其他版本目录 |

| 启动参数需要与插帧叠加 | 覆盖整段启动项会丢掉原设置 | 只合并已审核加载器参数，先备份、比较、写入、回读；保留 dxgi 和外部更改 |
| 未适配包不能凭文件名猜安装位置 | ZIP 布局、可选版本和前置不统一 | 专用适配和显式根目录模式分开；保留包内目录，先预览，冲突确认，可禁用/卸载/恢复 |

## 界面与授权

- 文件选择器取消、延迟回复及游戏切换都必须结束忙碌状态，并丢弃旧上下文结果。
- 手柄返回事件要验证真实冒泡与双按行为；DOM 测试不能代替手柄实测。
- 策略/游戏/MOD 列表折叠只改变显示，不应丢失选择、任务或启用状态。
- API 已绑定不代表浏览器已登录。普通会员仍需网页确认文件下载；不同浏览器的登录状态可能独立。
- 已有本地压缩包不需要 API 授权。说明读取按需进行，网络失败保留本地信息。
- 中国大陆访问 GitHub 失败时，提供真实直达的局域网签名包；短链接跳回同一受阻地址不能算解决。

每次新增修复先记录可复现触发条件，补能证明行为的回归，再改代码并独立审阅。
不承诺“所有游戏/所有 MOD 完美兼容”，也不把更多测试数量当作真实游戏效果证明。

## 本次十轮迭代补充

- 读取更新状态暂时失败后，成功轮询必须清除对应旧提示；操作错误不能被无关轮询掩盖。
- 更新清单只在内存时，重启后不能因磁盘上的旧检查时间漏查；设置写盘失败不能改变当前设置。
- 慢绑定请求不能覆盖新账号或恢复已解绑账号，用可控并发测试检查落盘结果。
- 签名正确不等于安装包完整；必需后端、解压模块和游戏数据必须存在且非空。
- 脱敏覆盖实际 key/auth 结构、Base64 字符、环境变量、HTML 转义及 HTTPS 下载授权；错误只报文件名，不回显内容。
- 初始化线程不可因取消而遗失；重复取消、卸载过程中删除，以及卸载后删除都要测。不能因清空服务引用而丢失原 NXM 关联恢复入口。
- 恢复成功清除对应旧错误；安装/启用与前置恢复共用锁，不能让已启用资源 MOD 失去加载开关。
- 同一网页回调重复送达只产生一个活跃任务；失效游戏的同编号记录不能阻挡其他游戏。
- 响应可解析不代表下载完整；校验声明长度，同时接受 HTTP 合法空白。进度回调失败也要关闭文件句柄。
- 一个游戏读取失败不能阻断整个页面；目录断开或安装身份改变必须使旧界面及旧异步结果失效。
- 游戏列表与详情并行读取时可能对应不同安装快照；身份不一致须等待重新确认，运行或维护标记任一为真就继续保护。手动扫描失效后，已有 MOD 的启用、禁用和卸载也必须立即锁定，不能只保护新导入入口。

逐轮版本和验证见 [ITERATIONS.md](ITERATIONS.md)，本次验证范围见 [VALIDATION.md](VALIDATION.md)。

## 扩展安装方式与更新误拦截

- Steam StateFlags 不是单一枚举值；待更新或暂停不等于正在写盘。MOD文件写入继续保守锁定，插件升级只区分活跃维护；未知标记保持保守。
- 更新准备与打开Decky确认窗口分开处理；保留可操作且脱敏的实际原因，未知异常不回显原文。
- 安装指南中的候选分类不是写入权限；只有固定代码审核的游戏与格式可选择执行，客户端不能指定目标路径或handler。
- REFramework当前统一DLL与旧nonRT构建不能混装。SMAPI注释是数据，不能执行；依赖/最低版本需显示，不能把入口文件存在当成兼容验证。
- 扩大目录时还要检查两个目录内游戏的根目录重叠，不能只保护动态发现的未知游戏。
